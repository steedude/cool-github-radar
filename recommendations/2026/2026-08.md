## 2026-08-11｜第一次手動試跑

本輪先建立超過 20 個候選，再依總表去重、閱讀原始 README、確認是否只是 fork／課堂作業，最後留下 4 個。

### 1. [fulldecent/system-bus-radio](https://github.com/fulldecent/system-bus-radio) — 9.6/10

讓沒有無線電發射硬體的電腦，靠記憶體匯流排活動產生的電磁輻射播放 AM 訊號。

真正精彩的是它不把 EMI 當成需要消除的雜訊，而是把特定記憶體寫入指令產生的輻射調變成載波。作者示範過讓收音機在約 1580 kHz 收到〈Mary Had a Little Lamb〉，距離可達數公尺；專案也把它放進 air-gap 資料外洩與 TEMPEST 的脈絡。2026 年還加入 Apple Silicon 與 WAV 輸入實作。

- 類型：技術奇觀、資安與側通道
- 適合：讀原理、拿 AM 收音機或 RTL-SDR 實驗
- 維護狀態：低頻但仍有實質更新

### 2. [NARKOZ/hacker-scripts](https://github.com/NARKOZ/hacker-scripts) — 8.9/10

把「任何事情超過 90 秒就寫腳本自動化」的工程師都市傳說，真的做成一組腳本。

內容包括：晚上仍有 SSH session 就自動傳訊息說會晚回家；偵測特定同事求救信後自動回復 staging database；宿醉且早上沒有登入就寄出在家工作郵件；甚至算準走到公司的連網咖啡機需要多久，提前透過 telnet 開始煮咖啡。它介於真實故事、程式碼表演和工程師民間文學之間。

- 類型：工程師黑色幽默、工程師文化
- 適合：純欣賞；不建議直接把老舊憑證與郵件範例投入實際環境
- 維護狀態：內容型經典，近年無功能開發

### 3. [schollz/croc](https://github.com/schollz/croc) — 8.7/10

用一段短語就能讓兩台裝置安全傳送檔案或資料夾，跨 Windows、macOS、Linux、Android 與多種套件環境。

它不只是另一個「區網 AirDrop」：傳送方提供 code phrase，雙方以 PAKE 建立共享密鑰，再進行端對端加密；可以透過 relay 穿越不同網路，也支援續傳、多檔傳輸及自架 relay。這和你做過的 WebRTC 網頁 AirDrop 很接近，但選擇了「短語配對＋relay＋CLI」這條不同路線，很值得拿來比較協定與 UX。

- 類型：數位自主、實用異能工具
- 適合：直接安裝使用，也適合研究配對與傳輸設計
- 維護狀態：活躍，2026-08-10 仍有更新

### 4. [86Box/86Box](https://github.com/86Box/86Box) — 8.6/10

不是只模擬一套 DOS，而是低階模擬從 1981 IBM PC 5150 到較晚期 PCI PC 的整個硬體生態。

你可以挑 CPU、主機板、顯示卡、音效卡、SCSI、網路卡與 Roland 合成器等周邊，再跑 MS-DOS、舊 Windows、OS/2、BeOS 或 NEXTSTEP。它很像可操作的老電腦博物館：保存的不只是軟體畫面，而是不同年代硬體彼此相容與不相容的細節。

- 類型：復古硬體改造、數位博物館
- 適合：重建特定年代 PC、測試老軟體與探索硬體史
- 維護狀態：非常活躍，2026-08-11 當天仍有提交


## 2026-08-11｜第一次排程推薦

本輪建立 25 個候選，排除已分享項目、鏡像、停止維護且缺乏獨特價值的專案，以及和既有收藏功能高度重疊的候選後，選出 3 個。

### 1. [jart/cosmopolitan](https://github.com/jart/cosmopolitan) — 9.5/10

讓 C/C++ 編譯出的同一個執行檔，原生跑在 Linux、macOS、Windows、FreeBSD、OpenBSD、NetBSD，甚至 BIOS，而且不需要 Java 那類 VM 或直譯器。

它的核心是 Actually Portable Executable（APE）：把不同作業系統能理解的檔案格式與啟動方式疊進一個 polyglot binary。一般跨平台軟體是在每個平台各編譯一份；Cosmopolitan 試圖把「平台差異」藏進執行檔本身。實務上可使用 `cosmocc` 編譯器，也內建 `--strace`、`--ftrace` 等除錯能力，最小二進位檔可壓到十幾 KB。

- 類型：技術奇觀、數位自主、實用異能工具
- 實用方式：製作免安裝的跨平台 CLI、研究 executable format 與 libc
- 維護狀態：活躍；2026-07-20 仍有提交
- 為什麼適合你：概念像「軟體版的萬用轉接頭」，既能拆黑盒，又真的能編譯東西

### 2. [mgba-emu/mgba](https://github.com/mgba-emu/mgba) — 9.1/10

成熟、快速而且重視硬體準確性的 Game Boy Advance 模擬器，同時支援 Game Boy 與 Game Boy Color；正是比 86Box 更符合你「現在就能拿來玩」偏好的模擬器。

除了快轉、倒帶、即時存檔、手把與作弊碼，它還重現很多容易被簡化的周邊：卡匣震動與動作感測器、Boktai 太陽感測器、Game Boy Camera／Printer、e-Reader、RTC，以及同一台電腦上的 link cable。它甚至提供 Lua、GDB remote，能配合 Ghidra、IDA Pro 研究遊戲。

- 類型：復古硬體、實用工具、數位保存
- 實用方式：Windows／macOS／Linux 直接玩 GB、GBC、GBA，也能裝在 3DS、Switch、Wii、Vita
- 維護狀態：活躍；2026-08-06 仍在修正 Windows 壓縮檔相容性
- 為什麼適合你：同時滿足復古遊戲、立即可用與理解舊硬體三條線

### 3. [Genymobile/scrcpy](https://github.com/Genymobile/scrcpy) — 9.0/10

用電腦低延遲鏡像並控制 Android 手機，免 root、免在手機安裝 App、免帳號、無廣告，也不需要網際網路。

它利用 Android Debug Bridge 啟動暫時性 server，把手機編碼後的影像／聲音串流到電腦，再反向送入鍵盤、滑鼠、剪貼簿與 gamepad 事件；結束後不在手機留下常駐 App。它也不只投影：能錄影、熄屏操作、開虛擬顯示器、把手機相機變成 Linux webcam，或用 OTG 模式把電腦鍵鼠模擬成實體 HID。

- 類型：數位自主、實用異能工具
- 實用方式：電腦操作手機、Demo、錄影、測試行動版前端、使用實體鍵鼠或手把
- 維護狀態：非常活躍；v4.1 於 2026-07-10 發布
- 為什麼適合你：前端測試與日常使用都派得上用場，而且架構本身也值得研究

## 2026-08-14｜排程推薦

本輪建立 30 個候選，以 repository ID、正規化 owner/repo、fork／redirect 與功能語意去重；閱讀原始 README 並檢查近期提交後，選出 3 個。

### 1. [corkami/collisions](https://github.com/corkami/collisions) — 9.5/10

這是一座可操作的雜湊碰撞實驗室：它不只是告訴你 MD5 已經不安全，而是提供能在數秒內生成「內容不同、MD5 完全相同」檔案的範例與工具。

酷點在於碰撞區塊會搭配各種檔案格式的區塊、長度與註解機制，讓同一組碰撞位元控制真正被解析的內容。範例涵蓋 PDF、PNG、JPG、GIF、MP4、PE、ZIP、Office、EPUB 等，還展示一個檔案同時具有多種格式的 polycollision，以及多個雜湊同時碰撞的 pileup。

- 類型：技術奇觀、資安
- 實用方式：下載範例自行驗證 hash、研究檔案解析與數位簽章陷阱；請只對自有檔案與受控環境實驗
- 維護狀態：低頻但有實質維護；最近一批內容更新為 2025-02-19 至 2025-02-20
- 為什麼適合你：把抽象密碼學弱點變成肉眼可見、可以親手重現的檔案魔術

### 2. [WerWolv/ImHex](https://github.com/WerWolv/ImHex) — 9.2/10

一款為逆向工程與程式設計打造的現代 Hex Editor；除了桌面版，也有能立即試用的網頁版。

它最特別的是 Pattern Language：用類似 C++ 的描述把原始 bytes 解析成結構，自動標色並標註欄位。再搭配節點式 Data Processor、資料檢視器、雜湊與編碼工具、外掛，以及 STL 等格式的視覺化，你不是只在十六進位海裡找字串，而是在逐層拆解檔案格式與韌體。

- 類型：實用工具、資安、技術奇觀
- 實用方式：直接用 Web 版或安裝桌面版分析圖片、封包、ROM、韌體與自訂二進位格式
- 維護狀態：非常活躍；2026-08-12 仍加入 HMAC Hash 並修正視窗行為
- 為什麼適合你：兼具「拆黑盒」的樂趣與真正會留在工具箱裡的實用性

### 3. [The-Powder-Toy/The-Powder-Toy](https://github.com/The-Powder-Toy/The-Powder-Toy) — 8.9/10

一個免費開源的粒子物理沙盒，把氣壓與流速、熱、重力、液體、氣體、材料反應和電子元件放進同一張可以像小畫家般塗抹的畫布。

你可以炸東西，也能蓋核電廠、機械、電路，甚至用邏輯元件做 CPU。它的價值不只在模擬：社群累積了大量可直接載入的作品，Lua API 還能自動化操作或寫外掛，因此很容易從五分鐘玩具一路變成長期工程坑。

- 類型：技術奇觀、可立即實驗的工具／遊戲
- 實用方式：官網或 Steam 直接玩；從社群存檔逆向研究別人的機器，再用 Lua 改造成自己的實驗
- 維護狀態：非常活躍；100.1 版於 2026-08-07 更新，2026-08-14 又新增 destructibility view
- 為什麼適合你：比純博物館式模擬器更有操作性，又保留老派沙盒那種「規則簡單、組合爆炸」的味道
