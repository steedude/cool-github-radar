### 1. [fulldecent/system-bus-radio](https://github.com/fulldecent/system-bus-radio) — 9.6/10

讓沒有無線電發射硬體的電腦，靠記憶體匯流排活動產生的電磁輻射播放 AM 訊號。

真正精彩的是它不把 EMI 當成需要消除的雜訊，而是把特定記憶體寫入指令產生的輻射調變成載波。作者示範過讓收音機在約 1580 kHz 收到〈Mary Had a Little Lamb〉，距離可達數公尺；專案也把它放進 air-gap 資料外洩與 TEMPEST 的脈絡。2026 年還加入 Apple Silicon 與 WAV 輸入實作。

- 類型：技術奇觀、資安與側通道
- 適合：讀原理、拿 AM 收音機或 RTL-SDR 實驗
- 維護狀態：低頻但仍有實質更新

### 2. [NARKOZ/hacker-scripts](https://github.com/NARKOZ/hacker-scripts) — 8.9/10

把「任何事情超過 90 秒就寫腳本自動化」的工程師都市傳說，真的做成一組腳本。

內容包括：晚上仍有 SSH session 就自動傳訊息說會晚回家；偵測特定同事求救信後自動回復 staging database；宿醉且早上沒有登入就寄出在家工作郵件；甚至算準走到公司的連網咖啡機需要多久，提前透過 telnet 開始煮咖啡。它介於真實故事、程式碼表演和工程師民間文學之間。

- 類型：工程師黑色幽默、工程師文化
- 適合：純欣賞；不建議直接把老舊憑證與郵件範例投入實際環境
- 維護狀態：內容型經典，近年無功能開發

### 3. [schollz/croc](https://github.com/schollz/croc) — 8.7/10

用一段短語就能讓兩台裝置安全傳送檔案或資料夾，跨 Windows、macOS、Linux、Android 與多種套件環境。

它不只是另一個「區網 AirDrop」：傳送方提供 code phrase，雙方以 PAKE 建立共享密鑰，再進行端對端加密；可以透過 relay 穿越不同網路，也支援續傳、多檔傳輸及自架 relay。這和你做過的 WebRTC 網頁 AirDrop 很接近，但選擇了「短語配對＋relay＋CLI」這條不同路線，很值得拿來比較協定與 UX。

- 類型：數位自主、實用異能工具
- 適合：直接安裝使用，也適合研究配對與傳輸設計
- 維護狀態：活躍，2026-08-10 仍有更新

### 4. [86Box/86Box](https://github.com/86Box/86Box) — 8.6/10

不是只模擬一套 DOS，而是低階模擬從 1981 IBM PC 5150 到較晚期 PCI PC 的整個硬體生態。

你可以挑 CPU、主機板、顯示卡、音效卡、SCSI、網路卡與 Roland 合成器等周邊，再跑 MS-DOS、舊 Windows、OS/2、BeOS 或 NEXTSTEP。它很像可操作的老電腦博物館：保存的不只是軟體畫面，而是不同年代硬體彼此相容與不相容的細節。

- 類型：復古硬體改造、數位博物館
- 適合：重建特定年代 PC、測試老軟體與探索硬體史
- 維護狀態：非常活躍，2026-08-11 當天仍有提交


## 2026-08-11｜第一次排程推薦

本輪建立 25 個候選，排除已分享項目、鏡像、停止維護且缺乏獨特價值的專案，以及和既有收藏功能高度重疊的候選後，選出 3 個。

### 1. [jart/cosmopolitan](https://github.com/jart/cosmopolitan) — 9.5/10

讓 C/C++ 編譯出的同一個執行檔，原生跑在 Linux、macOS、Windows、FreeBSD、OpenBSD、NetBSD，甚至 BIOS，而且不需要 Java 那類 VM 或直譯器。

它的核心是 Actually Portable Executable（APE）：把不同作業系統能理解的檔案格式與啟動方式疊進一個 polyglot binary。一般跨平台軟體是在每個平台各編譯一份；Cosmopolitan 試圖把「平台差異」藏進執行檔本身。實務上可使用 `cosmocc` 編譯器，也內建 `--strace`、`--ftrace` 等除錯能力，最小二進位檔可壓到十幾 KB。

- 類型：技術奇觀、數位自主、實用異能工具
- 實用方式：製作免安裝的跨平台 CLI、研究 executable format 與 libc
- 維護狀態：活躍；2026-07-20 仍有提交
- 為什麼適合你：概念像「軟體版的萬用轉接頭」，既能拆黑盒，又真的能編譯東西

### 2. [mgba-emu/mgba](https://github.com/mgba-emu/mgba) — 9.1/10

成熟、快速而且重視硬體準確性的 Game Boy Advance 模擬器，同時支援 Game Boy 與 Game Boy Color；正是比 86Box 更符合你「現在就能拿來玩」偏好的模擬器。

除了快轉、倒帶、即時存檔、手把與作弊碼，它還重現很多容易被簡化的周邊：卡匣震動與動作感測器、Boktai 太陽感測器、Game Boy Camera／Printer、e-Reader、RTC，以及同一台電腦上的 link cable。它甚至提供 Lua、GDB remote，能配合 Ghidra、IDA Pro 研究遊戲。

- 類型：復古硬體、實用工具、數位保存
- 實用方式：Windows／macOS／Linux 直接玩 GB、GBC、GBA，也能裝在 3DS、Switch、Wii、Vita
- 維護狀態：活躍；2026-08-06 仍在修正 Windows 壓縮檔相容性
- 為什麼適合你：同時滿足復古遊戲、立即可用與理解舊硬體三條線

### 3. [Genymobile/scrcpy](https://github.com/Genymobile/scrcpy) — 9.0/10

用電腦低延遲鏡像並控制 Android 手機，免 root、免在手機安裝 App、免帳號、無廣告，也不需要網際網路。

它利用 Android Debug Bridge 啟動暫時性 server，把手機編碼後的影像／聲音串流到電腦，再反向送入鍵盤、滑鼠、剪貼簿與 gamepad 事件；結束後不在手機留下常駐 App。它也不只投影：能錄影、熄屏操作、開虛擬顯示器、把手機相機變成 Linux webcam，或用 OTG 模式把電腦鍵鼠模擬成實體 HID。

- 類型：數位自主、實用異能工具
- 實用方式：電腦操作手機、Demo、錄影、測試行動版前端、使用實體鍵鼠或手把
- 維護狀態：非常活躍；v4.1 於 2026-07-10 發布
- 為什麼適合你：前端測試與日常使用都派得上用場，而且架構本身也值得研究

## 2026-08-14｜排程推薦

本輪建立 30 個候選，以 repository ID、正規化 owner/repo、fork／redirect 與功能語意去重；閱讀原始 README 並檢查近期提交後，選出 3 個。

### 1. [corkami/collisions](https://github.com/corkami/collisions) — 9.5/10

這是一座可操作的雜湊碰撞實驗室：它不只是告訴你 MD5 已經不安全，而是提供能在數秒內生成「內容不同、MD5 完全相同」檔案的範例與工具。

酷點在於碰撞區塊會搭配各種檔案格式的區塊、長度與註解機制，讓同一組碰撞位元控制真正被解析的內容。範例涵蓋 PDF、PNG、JPG、GIF、MP4、PE、ZIP、Office、EPUB 等，還展示一個檔案同時具有多種格式的 polycollision，以及多個雜湊同時碰撞的 pileup。

- 類型：技術奇觀、資安
- 實用方式：下載範例自行驗證 hash、研究檔案解析與數位簽章陷阱；請只對自有檔案與受控環境實驗
- 維護狀態：低頻但有實質維護；最近一批內容更新為 2025-02-19 至 2025-02-20
- 為什麼適合你：把抽象密碼學弱點變成肉眼可見、可以親手重現的檔案魔術

### 2. [WerWolv/ImHex](https://github.com/WerWolv/ImHex) — 9.2/10

一款為逆向工程與程式設計打造的現代 Hex Editor；除了桌面版，也有能立即試用的網頁版。

它最特別的是 Pattern Language：用類似 C++ 的描述把原始 bytes 解析成結構，自動標色並標註欄位。再搭配節點式 Data Processor、資料檢視器、雜湊與編碼工具、外掛，以及 STL 等格式的視覺化，你不是只在十六進位海裡找字串，而是在逐層拆解檔案格式與韌體。

- 類型：實用工具、資安、技術奇觀
- 實用方式：直接用 Web 版或安裝桌面版分析圖片、封包、ROM、韌體與自訂二進位格式
- 維護狀態：非常活躍；2026-08-12 仍加入 HMAC Hash 並修正視窗行為
- 為什麼適合你：兼具「拆黑盒」的樂趣與真正會留在工具箱裡的實用性

### 3. [The-Powder-Toy/The-Powder-Toy](https://github.com/The-Powder-Toy/The-Powder-Toy) — 8.9/10

一個免費開源的粒子物理沙盒，把氣壓與流速、熱、重力、液體、氣體、材料反應和電子元件放進同一張可以像小畫家般塗抹的畫布。

你可以炸東西，也能蓋核電廠、機械、電路，甚至用邏輯元件做 CPU。它的價值不只在模擬：社群累積了大量可直接載入的作品，Lua API 還能自動化操作或寫外掛，因此很容易從五分鐘玩具一路變成長期工程坑。

- 類型：技術奇觀、可立即實驗的工具／遊戲
- 實用方式：官網或 Steam 直接玩；從社群存檔逆向研究別人的機器，再用 Lua 改造成自己的實驗
- 維護狀態：非常活躍；100.1 版於 2026-08-07 更新，2026-08-14 又新增 destructibility view
- 為什麼適合你：比純博物館式模擬器更有操作性，又保留老派沙盒那種「規則簡單、組合爆炸」的味道

### 1. [gchq/CyberChef](https://github.com/gchq/CyberChef) — 9.3/10

這是英國情報機構 GCHQ 開源的「Cyber 瑞士刀」：把編解碼、加解密、壓縮、雜湊、hexdump、字元編碼、憑證與網路資料解析，集中成一個可以拖拉組合的瀏覽器工作台。

它最有價值的不是工具很多，而是「recipe」機制：把多個操作串成可重現的資料處理管線，能即時查看中間結果、設 breakpoint、逐步執行，也能把 recipe 存進網址分享。一般輸入與 recipe 都在瀏覽器本機處理，不會送到伺服器；完整版本還能下載後離線使用或部署在封閉網路。

- 類型：實用工具、資安、數位自主
- 實用方式：處理 Base64／URL encoding、檔案雜湊、時間戳、壓縮資料、憑證與可疑字串；也適合把常用轉換流程存成 recipe
- 維護狀態：非常活躍；2026-08-18 當天仍有依賴與建置更新，repository 未封存
- 為什麼適合你：像把一整排零散 CLI 小工具變成可視化管線，而且敏感資料預設留在自己的電腦

### 2. [seemoo-lab/openhaystack](https://github.com/seemoo-lab/openhaystack) — 9.2/10

把 BBC micro:bit、ESP32 等一般藍牙裝置，變成能借用 Apple「尋找」網路回報位置的自製追蹤器。它不是官方 AirTag SDK，而是 TU Darmstadt 資安研究團隊逆向封閉協定後做出的研究框架。

配件產生 P-224 公私鑰，把公鑰放進 Bluetooth Low Energy 廣播；附近的 iPhone 看到後，會把位置加密上傳。Mac 端再透過 Apple 私有介面取得報告，並以只有自己持有的私鑰解密。最繞路的地方是它利用 Apple Mail 外掛繼承所需 entitlement，因此安裝時要暫時停用 Gatekeeper。

- 類型：技術奇觀、資安、數位自主
- 實用方式：拿 micro:bit／ESP32 在受控環境研究 BLE、群眾定位與端對端加密，不建議取代日常使用的 AirTag
- 維護狀態：repository 未封存，README 於 2026-08-17 更新；但最近實質程式維護主要停在 2024-07，官方也明示它是未完整測試的實驗軟體
- 限制：目前框架要求 Mac 與 Mail 外掛；範例韌體廣播固定公鑰，附近裝置可藉此持續辨認同一個標籤
- 為什麼適合你：它把 AirTag 背後的巨大群眾網路拆開，證明便宜的通用硬體也能接進原本封閉的能力

### 3. [hackclub/sprig](https://github.com/hackclub/sprig) — 9.0/10

Sprig 同時是網頁遊戲編輯器、社群作品庫，以及以 Raspberry Pi Pico 為核心的開源掌機。你可以直接在瀏覽器用 JavaScript 製作 tile-based 小遊戲，搭配內建 sprite、地圖、音效與音樂工具。

真正酷的是同一份 JavaScript 不只跑在網頁模擬器，也能跑在 RP2040 微控制器上；團隊為此製作自訂 JS runtime，並用 C 與 PIO assembly 最佳化。repository 連掌機 PCB、外殼、韌體、引擎與社群遊戲都公開，硬體還刻意設計成可拆解、重刷及改裝。

- 類型：復古硬體、社群知識、技術奇觀
- 實用方式：不用買硬體就能在 Web Editor 做遊戲並玩社群作品；想深入再依開源設計研究 Pico、螢幕、音訊與實體按鍵
- 維護狀態：社群非常活躍；2026-08-16 合併了 Sprig 版 DOOM，2026-08-17 仍有新遊戲進入 repository
- 限制：官方實體掌機主要是面向青少年的有限贈送計畫，並非常態販售商品；成年人仍可使用網頁工具與公開硬體設計
- 為什麼適合你：比單純模擬舊主機多了一層「自己造主機生態」，而且現在就能先在線上玩與做

## 2026-08-21｜排程推薦

本輪建立 29 個候選，涵蓋瀏覽器虛擬化、RFID／無線硬體、復古遊戲重建、數位自主工具與數位考古；再以 repository ID、正規化 owner/repo、redirect、fork、鏡像與功能語意去重。三個入選項目皆已閱讀原始 README、核對來源、實際機制與近期提交。

### 1. [copy/v86](https://github.com/copy/v86) — 9.4/10

在一個普通瀏覽器分頁裡，完整模擬一台 x86 PC，甚至能直接啟動 Arch Linux、FreeDOS、Windows 98／2000、Haiku、ReactOS、Android-x86 與多種實驗性作業系統。

它不是做一個長得像舊電腦的網頁：v86 會模擬 CPU、FPU、VGA、IDE、PCI、NE2000 網卡、Sound Blaster 16、軟碟機甚至撥接數據機，再把客體的 x86 機器碼於執行期間翻譯成 WebAssembly。它也提供存取快照、虛擬檔案系統、網路和可嵌入網頁的 JavaScript／TypeScript API。

- 類型：技術奇觀、實用工具、數位自主
- 實用方式：直接開啟線上 Demo 體驗 DOS、舊 Windows 或 32-bit Linux；也能上傳自己的合法 ISO／磁碟映像，或以 npm 套件嵌入自己的網站
- 維護狀態：活躍；2026-08-09 仍新增平行埠模擬，並持續補齊 DOS 與 Windows NT 文件
- 限制：目前約為 Pentium 4 指令集層級，不支援 x86-64 與多核心；較新的 64-bit 系統不適合
- 為什麼適合你：它既是可立即玩的復古電腦，又是非常適合前端工程師拆解的「瀏覽器究竟能模擬到什麼程度」實驗

### 2. [RfidResearchGroup/proxmark3](https://github.com/RfidResearchGroup/proxmark3) — 9.2/10

Proxmark3 是 RFID／NFC 研究領域的瑞士刀；這個 repository 則是目前功能非常完整、持續開發的 Iceman 社群版本。配合 Proxmark3 實體裝置，可以辨識、讀寫、嗅探、模擬與分析 125／134 kHz 低頻及 13.56 MHz 高頻標籤。

它的特殊之處是同時掌握無線訊號與協定兩層：FPGA／韌體負責和卡片通訊，電腦端 client、Lua 與 Python scripts 則負責辨識晶片、解析資料和自動化研究。某些 standalone mode 還能讓裝置以電池獨立運作，不必一直連著電腦。

- 類型：實用工具、資安與側通道、技術奇觀
- 實用方式：研究自己持有的門禁卡、交通票證或 RFID 標籤協定，辨認 Flipper Zero 較難深入處理的卡片；只限自有設備或取得明確授權的測試
- 維護狀態：非常活躍；2026-08-21 當天仍加入 iCLASS raw command 並合併修正
- 來源說明：它源自 Jonathan Westhues 的原始 Proxmark3，但早已演化成有大量新指令、腳本、硬體支援與獨立社群的 Iceman 版本，不是沒有差異的普通鏡像
- 限制：必須另購相容硬體；官方主要針對 RDV4，廉價 clone 的記憶體與 FPGA 配置可能不同，而且 repository 本身屬快速變動的 bleeding-edge 版本
- 為什麼適合你：如果 Flipper Zero 是好上手的隨身多工具，Proxmark3 更像能深入卡片訊號與協定內部的工作台

### 3. [pret/pokeemerald](https://github.com/pret/pokeemerald) — 9.1/10

這不是另一個《寶可夢 綠寶石》ROM 下載站，而是把原本只有 GBA 機器碼的遊戲，長年逆向重建成可以閱讀、搜尋、編譯與修改的 C／ARM 組合語言專案。

它最漂亮的驗證方式是可重現建置：依照工具鏈編譯後，會產生 SHA-1 為 `f3ae088181bf583e55daf962a92bb46f4f1d07b7` 的 `pokeemerald.gba`，與指定原版完全相符。也因此，地圖、戰鬥、寶可夢數值、事件腳本、圖像、音效與存檔結構不再只是 Hex Editor 裡的位元，而成為能真正修改的程式碼。

- 類型：從零重造、數位保存、可實驗工具
- 實用方式：研究 GBA 遊戲架構、編譯自己的合法備份、修改事件與系統，或作為 Pokémon ROM hack 的乾淨技術底座
- 維護狀態：活躍；2026-08-20 仍有一致性整理與編譯匹配修正
- 限制：需要安裝 ARM／GBA 建置工具鏈；編譯後 ROM 涉及任天堂著作權，不應公開散布
- 為什麼適合你：它同時滿足 GBA、逆向工程和「把封閉黑盒變成可修改原始碼」三個興趣，而且不是只能參觀的博物館
